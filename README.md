# gorilasbillar

Landing page de **Gorilas Mesas de Billar**: mesas de billar fabricadas sobre pedido en Hermosillo, Sonora.

Sitio estático (HTML, CSS y JavaScript sin dependencias):

- `index.html`: la página.
- `css/styles.css`: estilos.
- `js/main.js`: franja de confianza, menú móvil, carrusel de trabajos, preguntas frecuentes y animaciones al hacer scroll.
- `assets/`: logo y fotos.

Para verla en local, abre `index.html` en el navegador o sirve la carpeta (por ejemplo `python3 -m http.server`).
Se puede publicar tal cual en GitHub Pages, Netlify o cualquier hosting estático.
